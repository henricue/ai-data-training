# Munakellon speksi

## Tavoite

Toteuta selaimessa toimiva munakello.

## Vaatimukset

- Sovellus koostuu yhdestä `index.html`-tiedostosta.
- Kaikki HTML, CSS ja JavaScript ovat samassa tiedostossa.
- Sovelluksessa on Start-, Pause- ja Reset-painikkeet.
- Käyttäjä voi säätää kellon kestoa.
- Sovellus toimii selaimessa ilman asennuksia tai käännösvaihetta.
- Ulkoisia kirjastoja ei käytetä.

# Harjoitus 5: Tilastollisten mallien laatiminen

Tutkimuskysymys:

> Miten sää vaikuttaa kaupunkipyörien kysyntään?

## Tehtävä

1. Selvitä vähintään kaksi aineistoon ja tutkimuskysymykseen sopivaa numeerista
   menetelmää.
2. Vertaa menetelmien käyttötarkoituksia, oletuksia ja soveltuvuutta.
3. Valitse perustellusti yksi menetelmä ja sovella sitä aineistoon.
4. Arvioi mallin toimintaa tarkoituksenmukaisilla tunnusluvuilla.
5. Kuvaa tulokset, oletukset, puutteet ja ongelman kannalta olennaiset
   reunaehdot.
6. Tallenna analyysi uudelleenajettavaan Python-skriptiin ja raporttiin.

Käytä raportin pohjana
[MODEL_REPORT_TEMPLATE.md](MODEL_REPORT_TEMPLATE.md)-tiedostoa.

## Vinkit

Käytä omaa käsiteltyä aineistoasi tai varatiedostoa
`data/reference/citybike_weather_daily.csv`.

Muista erottaa aineistossa havaittu yhteys kausaalisesta vaikutuksesta. Tämä
aineisto ei yksin osoita, että sää aiheuttaa havaitut muutokset kysynnässä.

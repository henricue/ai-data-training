# Harjoitus 4: Visualisointien laatiminen

Tutkimuskysymys:

> Miten sää vaikuttaa kaupunkipyörien kysyntään?

## Tehtävä

1. Laadi selaimessa toimiva aikasarjanäkymä kaupunkipyörien kysynnästä ja
   olennaisista säämuuttujista.
2. Tee näkymästä interaktiivinen siten, että käyttäjä voi valita ajanjakson ja
   tarkastella sitä tarkemmin.
3. Tyylittele sovellus ja kuvaajat [HSL:n tyylioppaan](https://tyyliopas.hsl.fi)
   mukaisesti.
4. Huolehdi, että kuvaajissa näkyvät selkeät otsikot, yksiköt ja lähteet.

Käytä toteutukseen Streamlitiä ja Plotlyä. Nykyinen aineisto sisältää yhden
vuoden, joten voit toteuttaa porautumisen esimerkiksi kuukausinäkymästä valitun
kuukauden päiväkohtaiseen näkymään.

## Vinkki

Käynnistä sreamlit-sovellus:

```bash
streamlit run polku/tiedostoon.py
```

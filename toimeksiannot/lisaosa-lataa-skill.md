# Lisäosa: lataa valmis skill itse

Netissä on paljon valmiita skillejä. Skill on ohjeita, joita agentti noudattaa, joten se
luetaan ennen kuin se otetaan käyttöön.

1. Avaa tämä skill selaimessa. Linkki osoittaa tiettyyn versioon, joten sisältö ei muutu:
   https://github.com/mattpocock/skills/tree/5beb35b040e3de97e54fa9e386d7e42d15c295c2/skills/productivity/wait-what
2. Lue kansion kaikki tiedostot. Mitä skill käskee agenttia tekemään? Onko mukana jotain,
   mitä et halua agentin tekevän?
3. Jos päätät ottaa sen käyttöön, kopioi kansio repoon polkuun `.github/skills/wait-what/`.
4. Vertaa sitä omaan `/selita`-skilliisi. Mitä tekisit toisin?
